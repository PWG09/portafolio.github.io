# Carlos Wiebe Baca — Portafolio

[![Ver sitio en vivo](https://img.shields.io/badge/portfolio-live-9cff57)](https://pwg09.github.io/portafolio.github.io/)

Portafolio personal de **Carlos Wiebe Baca**, desarrollador de software y creador de productos digitales. Actualmente en Canadá, con el objetivo de continuar su formación en desarrollo de software en una universidad canadiense.

## Sobre mí

Construyo productos digitales, aplicaciones web y herramientas SaaS orientadas a resolver necesidades reales. Mi experiencia combina proyectos prácticos, desarrollo de producto y **tres semestres cursados de Ingeniería en Desarrollo de Software en Universidad Tecmilenio**. Tecmilenio aparece como formación previa, no como estudios actuales.

Estoy enfocado en seguir desarrollando mis habilidades técnicas y de producto mientras preparo mi siguiente etapa académica en Canadá.

## Qué encontrarás en el sitio

- **Proyectos:** productos digitales, aplicaciones web y trabajos académicos.
- **CBDEVS:** estudio de desarrollo de software y soluciones a medida.
- **DetailFlow:** plataforma SaaS para negocios de detailing.
- **Experiencia y proceso:** cómo abordo el diseño, desarrollo, seguridad, pruebas y despliegue.
- **Stack técnico:** herramientas usadas en proyectos recientes.
- **Educación:** estudios previos en Tecmilenio, formación complementaria y certificaciones.
- **Contacto:** enlaces profesionales y canales de contacto.

El sitio incluye selector de idioma (español/inglés), modo claro/oscuro, filtros de proyectos y diseño adaptable a móvil y escritorio.

## Stack del portafolio

HTML, CSS y JavaScript puro, sin framework ni proceso de compilación. La web está diseñada para desplegarse en GitHub Pages.

Clona el repositorio y abre `index.html` en un navegador. No se requiere instalar dependencias.

```bash

cd portafolio.github.io
```
